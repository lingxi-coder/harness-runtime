## `allow_suggestion.rs`

### [P2] PERM-SUG-04 — AllowAlways bash narrowing diverges from CC ruleSuggestions: wrong bytes (':*' vs ' *'), wrong prefix algorithm, missing exact-command fallback
- **Where**: `lingxi-code/permission/src/allow_suggestion.rs:123`
- **Gap**: CC 2.1.211 persists the chosen Bash suggestion as a WILDCARD rule `Bash(<prefix> *)` (t9r appends ' *', destination localSettings), where the static prefix ($ro) is exactly TWO tokens, requires every leading env assignment name to be in the Jqr safe set (else NO prefix), requires the second token to match /^[a-z][a-z0-9]*(-[a-z0-9]+)*$/ and the first token's basename to be outside the interpreter blocklist, with heredoc (MOg) and multiline (Nd) special-casing; anything else falls back to an EXACT full-command rule (YYn). The Rust port persists `Bash(<root>:*)` where root is ALL leading non-flag tokens after stripping ALL env vars. Result: broader-than-CC grants — `ls` → Rust `ls:*` (matches every ls invocation) vs CC exact `ls`; `FOO=1 systemctl restart nginx` → Rust `systemctl restart nginx:*` (env dropped, prefix) vs CC exact `FOO=1 systemctl restart nginx`; `cat /etc/hosts` → Rust `cat /etc/hosts:*` vs CC exact — violating the module's own 'never broader' invariant — plus a byte-format mismatch (':*' vs ' *') in the persisted settings.local.json rule.
- **Fix**: Port the KQt chain: (1) heredoc → prefix of text before '<<' with the same safe-env/two-token rules; (2) multiline → first-line prefix; (3) $ro: abort to EXACT full-command rule_content when any leading env name is outside a ported Jqr set, when fewer than 2 non-env tokens, when token0 basename is an interpreter (Bro), or when token1 fails /^[a-z][a-z0-9]*(-[a-z0-9]+)*$/; otherwise emit exactly two tokens; (4) emit `"{prefix} *"` (wildcard) as rule_content and teach call_matches_rule/persist to treat it via the existing wildcard matcher; fallback = exact command, not tool-wide.

### [P1] PERM-AST-VARSCOPE-01 — for/if/while scope machinery diverges: no pre-scan/merge (E3i/dUr), loop-var guard far narrower, select accepted
- **Where**: `lingxi-code/permission/src/bash_ast_security.rs:929`
