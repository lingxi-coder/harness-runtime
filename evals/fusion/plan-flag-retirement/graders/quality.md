The first problem is telling the three groups apart, and a strong plan says how. Look for:
evidence used to classify a flag, such as evaluation telemetry rather than a guess; what
is done about a flag with no traffic at all; the order in which code and configuration are
removed and why that order matters; how a flag that turns out to be load-bearing is
caught before it is deleted; and a policy that keeps the problem from returning. Penalise
a plan that starts by deleting flags it believes are dead.
