## Comparison rules

- Compare raw bytes at observable seams: provider request/response and stream,
  hook input/result/error, MCP frames, persisted JSONL, and emitted client text.
  Do not parse and reserialize captured Native output before comparison.
- Fix the clock, IDs, absolute fixture paths, cwd, symlink tree, settings,
  locale, timezone, environment, provider responses, ordering and session input
  where the public test seam permits it. Preserve and compare original bytes;
  never remove fields, sort output, or normalize generated values to manufacture
  a byte pass.
- If Native generates a timestamp, UUID or other value that cannot be fixed,
  save the raw artifact and test that field as its own contract: type/encoding,
  exact format, uniqueness or reuse, references across request/event/session,
  ordering, lifecycle and persistence. These checks can close field-level
  invariants but do not make a differing full artifact byte-equal. Compare fixed
  fields and fixed sub-artifacts byte-for-byte; mark a dynamic whole-artifact
  byte comparison unavailable only when the remaining value prevents it.
- The Commands surrogate fixture is an explicit two-boundary case: the raw
  stream-json input and Native session JSONL preserve the lone UTF-16 unit;
  final Claude Messages JSON converts the body string value to U+FFFD according
  to `normalize_native_generation_json_body`, while object keys retain their
  own exact semantics. Preserve raw request and session bytes and assert both
  sides independently.
- Compare Native request bytes only for matching Claude/Anthropic routes. Other
  providers keep their own SDK contracts and tests; authorized wire differences
  are not normalized or treated as Claude parity.
- Keep the explicit differences: LingXi branding, multiple LLM providers,
  Fusion typed scalar prompt, and Create Local App. No older-version aliases or
  migration compatibility paths. The approved Computer Use scope includes the
  two minimal Source carrier/owned-id/native_query_depth adaptations and any
  required current DTO tests/call-site synchronization. Computer Use execution
  and validation algorithms remain owned by its other session; integrate and
  verify their current changes without duplicating, masking, or claiming those
  algorithm gates passed here.
- `Passed` requires evidence from the final same candidate. A source oracle or
  package test can be retained as scoped regression evidence, but cannot stand
  in for an unavailable Native or product-surface gate. Mark unavailable
  Native execution `Blocked/Unverified`, never `Done`.
