# Native 2.1.295 ListMcpResourcesTool cache-path observation

This isolated public CLI run used a pinned 2.1.295 binary, strict `--mcp-config`, a local stdio MCP server, and a loopback-only Messages stub. The model request exposed `ListMcpResourcesTool`; the stub called it for `server_name: fixture`. Native returned the resource received during startup discovery, and its raw MCP trace contains only one `resources/list` request, before the model request. No second request was made by the model tool, so this invocation did not reach a pending model-triggered `resources/list`; the SIGINT monitor sent no interrupt and no cancellation notification was observed.

The raw stdout, session JSONL, full MCP request/response stream, model request/response, debug log, fixture, and capture receipt are preserved here and hashed in `manifest.json`. The native debug log reports sending SIGINT to the MCP child during normal CLI shutdown after the successful result; that is separate from the external SIGINT probe and must not be counted as cancellation behavior. The run establishes a cache-backed public path and a reachability limit only; it is not a cancellation pass. The isolated `.claude.json` is intentionally not copied.
